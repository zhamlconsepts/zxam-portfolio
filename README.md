# zxam-portfolio

> **Ablakimov Jamshid (zxam)** — Junior Frontend Developer & UI Engineer Portfolio.
> Built with React.js, Tailwind CSS, Vite, HTML5 Canvas Navier-Stokes fluid simulation, GSAP, and a background ambient audio player engine.

---

## ✨ Features

- **Negative Inversion Cursor & Fluid Canvas**: High-speed Navier-Stokes fluid ink trail simulation with dynamic difference-mode typography inversion.
- **Atmospheric Background Audio Engine**: Autoplays a random track on first arrival, supports shuffle, repeat modes, interactive seek bar, volume regulation, and a live playlist drawer.
- **Featured Live Projects**:
  - [Call Our Hero (COH)](https://call-our-hero-coh.vercel.app/) — Smart civic eco-logistics dispatch platform.
  - [Panthera Pardus](https://zoo-pi-ten.vercel.app/) — 120-frame scroll-scrubbed interactive 3D monograph.
- **Multilingual Support**: Real-time localization across Uzbek (UZ), Russian (RU), and English (EN).
- **Luxury Brutalist & Swiss Editorial Aesthetic**: Deep obsidian palette (`#08080a`), high-contrast typography, laser-red accents (`#e60000`), and responsive layouts.
- **Interactive Modals & CV**: Built-in resume viewer with printable / PDF-export support and detailed project modals.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS
- **Animations**: GSAP, Lenis Smooth Scroll
- **Canvas Physics**: Navier-Stokes Fluid Solver & HTML5 Canvas 2D
- **Icons**: Lucide React
- **Sound Design**: Web Audio API & HTML5 Audio

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
